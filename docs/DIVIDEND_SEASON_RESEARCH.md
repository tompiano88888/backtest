# 当前套利分红调整方法

当前节点见[研究节点](RESEARCH_CHECKPOINT.md)。固定全收益版本3f899b4d11604eef86a318e7496f9741，data/index_total_return；IF/IH/IC/IM对应H00300.CSI/H00016.CSI/H00905.CSI/H00852.CSI，仅作研究参考。

仅5—8月计入预测，以此前3个完整年度同月均值累计(day,expiry]与5—8月交集，按自然日分配；其他月份贡献为0，不把全年金额重摊进四个月。即使当前在4月，未来5月区间也计入；8月跨9月仅计未来8月部分。

调整后的信号同时用于历史训练、开平判断与排序，重做35组滚动参数，再扫描额外下限。缓存必须匹配月份、模型与全收益版本；不能复用全年或不含分红的选择表。

## 分析口径


对齐同一编制口径的价格指数P与全收益指数TR，使用相邻共同交易日的
`TR[t]/TR[t-1] - P[t]/P[t-1]`估计当日现金分红收益贡献。
该差值不是两个指数点位直接相减，也不是ETF派息率。
使用官方对应全收益系列，不混用净收益系列；仍需注意供应商历史修订和早期回溯。
共同覆盖区间内任一交易日期不匹配即报错，禁止跨缺失日期计算收益差。
早期历史存在明显负向异常，月度贡献保留带符号原始差值，不静默截断或填零。

只用决策日前已结束历史年度估计未来至合约到期之间的季节分红贡献。
历史训练窗口内的每个信号按其自身日期形成预测，禁止用训练窗口末端
的信息回填整个窗口。第一版固定此前3个完整年度，按月汇总收益差再跨年取均值，
按预测月份实际自然日数均匀分配到(day,expiry]；闰年及跨年按实际月份处理。
年初/年末覆盖及12个月完整性检查不通过时预测不可用；负区间预测也不可用，
不默认为零分红。月内均匀分配为季节性估计，不声称预测具体股票除息日。
不按全样本收益挑选模型窗口。2020回测所需2019训练信号使用2016—2018历史。
下载时间保留为真实known_at；历史日期切分不等于历史版本PIT已验证。

设预测分红收益比例为q_hat，调整信号为
`[(F-S)/S + q_hat] * 365 / remaining_calendar_days`。
与开仓下限h比较，等价于原始年化基差门槛
`h - q_hat*365/remaining_calendar_days`；避免同时调整信号和门槛造成双算。
到期及以后不计算年化率，预测缺失不默认零分红。


## 执行与边界

预测只改变信号，不额外记入PnL；实际ETF分红、原价成交、期货结算及回购仍按原账务。月度均匀分配、供应商历史修订／PIT、全样本下限寻优、代理评分及同日事后撤计划等限制保留。当前复现命令见节点文档，扫描入口scripts.scan_arbitrage_entry_floor，汇总scripts.summarize_dividend_season_research --may-aug。
