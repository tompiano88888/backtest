# ATR20／1%风险节点：避免平今费的执行路由


用户2026-10-20确认：所有平仓（包括为新信号平反向仓的解锁）都检查同一实际合约、同一持仓方向的当日计费余额。非零时不平该方向，改为反向开仓；余额为零时优先平反向锁仓实现净方向入场，库存不足再新开。用户同意当天再次释放敞口时继续新开，不能把当天对锁的反向仓平掉。

## 保留的策略基底

基于当前ATR20×1／入场决策权益1%风险定仓节点，无逐分钟5%分批、不主动加仓、不采用滚动历史权重。主力选择、六价位参数、盘中反转、14:59隔夜及止损冷却沿用原回调。风险手数、冻结ATR和1%风险预算不按新物理开仓重复计算；解锁与新开合计共用同一原入场目标和风险额度。策略预计费用公式仍沿用万0.23，实际已扣费用和权益来自唯一真实账户。

固定原行情区间及快照、1000万元初始资金、15%研究保证金、10%成交量参与率、连续不利1tick及竞价零滑点。实际费用继续由历史FeeService计算，使用configs/ifind.index-futures-fees.json的固定版本/as_of，today_first匹配，佣金为零；不减免或改写框架费用。

## 执行与状态

- 增加多头方向：对面空仓有可按普通平仓收费的锁仓库存时先买平空仓；如果当天开过空且计费余额未消耗，或反向库存不够，则买开多仓补足。增加空头方向对称。
- 退出方向：该方向当日计费余额为零则直接平仓；非零则等量开反向仓，使净方向退出。锁仓后净敞口结束，但真实持仓和保证金继续存在。
- 按实际成交维护余额，不按下单维护；跨交易日按新交易日重置。未成交余量持续处理，新的目标替换旧目标，不能同时保留已被替换的对锁开仓及直接平仓。
- 当前主力的零净敞口锁仓留待信号释放；旧主力按已知昨日主力映射在次日09:25提交清理，09:30竞价最早成交。未完成的旧主力库存阻止同品种新主力入场；竞价后才出现的信号不能回填竞价。
- 不同月份不作为完全对锁抵消。方向预算按同实际合约多空相抵后的敞口计算，品种净方向保证金等价量50%；总实际资金占用按真实多空单向大边计算，达到90%停止新增方向，包括解锁。未成交风险减少单不提前释放额度。
- 为本轮显式启用既有execution_guard，在真实竞价/连续开盘价及真实费用处再次缩量或暂缓；不读取当根分钟高低收盘或结算价。风险减少的保护性对锁不能把实际保证金提高到90%限制与既有保证金两者较大值之外；无法完成则保留退出意图。不主动强平，被动超过100%如实记录并判资金可行性未通过。

## 统一账务与逻辑方向交易

新增外部FeeAvoidingRBreaker只包装原PortfolioRBreaker及TradeStops。所有真实开仓、解锁、保护性对锁和库存清理都由ctx.target_group进入同一Engine/FeeService/Ledger；不建立第二套执行或现金账本。

方向风险簿仅依据已发生的真实成交生成净敞口观察：买平旧空形成新多敞口，等价于以真实成交价格取得多头风险；卖开保护性空仓则结束相应多头风险。原TradeStops用这些实际成交价格、费用维护冻结风险预算、ATR、部分成交及冷却。日终结算不重置方向风险基准。

清理旧锁仓产生的额外费用与双边成交时间/价格差单列inventory_cleanup_adjustment。逻辑方向交易PnL＋该库存调整必须等于真实账户PnL；不用逻辑方向曲线替代实际资金曲线。账户、品种归因、保证金和每日结算始终使用真实Ledger。


复现须使用新输出目录，不覆盖节点或封存。routing_fills.csv逐笔标明enter_open、enter_unlock、exit_close、exit_hedge、cleanup及平今余额；logical_fills.csv为实际成交衍生的净方向观察；order_routing.csv记录目标与在途取消；fee_details.csv仍是框架真实计费。

execution_guard.csv记录真实开盘准入；funding_observations.csv包括开盘、逐笔成交后、分钟末和结算观察，funding_breaches.csv保存全部实际资金超限。daily_pnl_funding.csv及pnl_and_daily_funding.png展示逐日PnL和结算后资金使用率。分钟/Tick内未观测路径不作保证。

minute_risk.csv中的各品种usage及summary的max_minute_product_margin_ratio是物理大边占用，不是净方向额度。旧字段mark_to_market_cap_breach_minutes沿用统计“总实际占用超过90%或品种物理占用超过50%”的观察次数；本轮品种准入限制是净敞口50%，不能把该字段误解为净敞口准入违规次数。真实净敞口见funding_observations的品种exposure列及逐笔准入独立审计。

独立核验先按供应商原始记录重算每笔费用及today_first余额，再回放真实FIFO、原始开盘/成交量参与率、全量资金观察和净方向取得/退出。验收平今计费手数必须为0；账务/准入与资金可行性分别报告。历史供应商修订/PIT、分钟标签及15%固定保证金假设继续保留。
