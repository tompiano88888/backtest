# R-Breaker年度多维归因

基于当前历史手续费对锁节点已验证的逐笔逻辑方向交易，只扩展归因与制图，不改变信号、库存路由、资金约束、撮合、费用、结算或研究节点。

入口 `python -m scripts.report_rbreaker_yearly_multidim`；只做统计用 `--analyze-only`，只做制图用 `--plot-only`。默认输入 `outputs/rbreaker_signal_diagnostics_20261022/trade_labels.csv`，输出 `outputs/rbreaker_yearly_multidim_20261022`。统计使用Python标准库Decimal，制图需要matplotlib/numpy与中文字体。

输出包括年度、年度×入场、年度×品种、年度×品种×入场、年度×入场×退出、年度×品种×入场×退出、年度×品种×入场×方向七张CSV汇总。`statistics.json`包含全部分组与统计定义，`report.md`为完整分析。PNG用于分享，SVG可编辑，HTML为离线交互图。

图以入场年份为横轴、品种与突破/反转为纵轴。总面积与方向交易笔数成正比，外圈颜色为完整交易的平均净R，内圆扇区按退出原因的笔数构成，气泡下方标净PnL万元与观察止损率。全图使用同一个以零为中心的对称线性色标，未在行内重新缩放。扇区绘制固定共同边界，避免窄扇区被单独归一化而失真。

整笔生命周期PnL归实际入场年；跨年交易不拆分，因此不是账户年度PnL。2026仅至10月8日，IM从2022年起。四笔未结束交易的期末估值计入净PnL与观察笔数，胜率/平均R仅完整交易。R=单笔净PnL/入场冻结风险预算，是归一化逐笔表现，并非组合收益率。退出原因的止损优先规则沿用原只读归因；不把对锁执行当反转入场。真实库存清理调整另行核对，不强行摊给信号类型。

52个年度×品种×入场组、144个再分退出原因组，全部笔数、完整笔数、止损与净PnL加总一致，逐年独立重算平均R并核对。方向净PnL19730260.46350元＋库存调整168585.85780元＝账户19898846.32130元。原始逐笔文件SHA256保持不变，分析记录在`analysis_checks.json`。两项原有统计口径测试通过，新脚本编译通过；此轮不将之前361项全框架测试宣称为新运行。

分析属于历史条件归因。退出原因与持有时长是事后分组，年份、品种与费用环境也不独立；少量交易的零止损率不能解释为未来概率为零。任何信号过滤验证继续沿用当前对锁原则与真实费用，另设回测对照，不能直接从本分组表推导删去交易后的结果。
