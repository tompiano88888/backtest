# 2026-10-20 回测框架费用版本核验

本次Git仅发布统一框架、费用接口及必要测试文档，策略源码、行情/费用DuckDB、原始缓存、回测结果不纳入。数据库获取和配置方式见[历史费用](INDEX_FUTURES_FEES.md)。本版本仍不是完整V1验收。

## 已确认能力

- Engine/FeeService根据真实成交统一计算交易所费用、佣金及账本扣费；指令流水和回调共用配置，普通Bar、离散竞价及缩量报价同源。
- fifo保持原批次计费；today_first跨group按同合约同持仓方向先抵当日实际开仓数量。昨多10/今开3/平5为3手平今、2手普通；先平后开不追补、对锁开仓收开仓费，真实FIFO成本不变。
- commission_rate及commission_per_unit可同时配置，默认零，交易所平今优惠不减免佣金；连续滑点和竞价零滑点规则保持。
- historical显式使用固定DuckDB版本/as_of按交易日取规则，缺失或冲突报错；fixed研究模式保持兼容。结果包含逐笔费用拆分及来源。

## 本次验证

从Git HEAD提取已跟踪基础文件，再仅加入本次选定增量，在不含策略模块、历史数据库和缓存的独立目录运行全部测试：182项通过；compileall及demo通过，demo PnL52、4条预期组合警示。完整本地研究工作区363项测试通过。
