# 显式竞价容量仿真

`Engine(..., auction_volume_exemption=predicate)`可由外部调用方显式选择某些竞价指令忽略成交量限制。默认None，普通Bar、竞价默认参与率及其他订单的共享量不变。

predicate接收不可变Instruction，必须返回bool。仅当存在显式Auction行情且标的处于可交易集合时调用；True使该指令不受Auction.volume和参与率预算限制，也不消耗其他非豁免订单的共享预算。它只放宽竞价容量，不绕过可平数量、T+1、最小单位、停牌、涨跌停、委托限价、执行守卫和费用。

该选项用于调用方明确披露的理想化研究，例如用已知价格构造价格参考竞价事件，并假定选定余量可全部成交。未知真实竞价量可显式保留volume=0，不得伪造大成交量。没有Auction价格事件时仍不能成交，参考价格的来源、可知时点和仿真假设必须由外部运行配置记录；不能将容量豁免结果宣称为真实成交保证。

每笔竞价成交的execution_details记录`method='auction'`、原始bar_volume及`auction_volume_exempt`，实际费用、现金、权益及组合归因照常计算。必须在竞价事件发生之前提交指令，回调看到竞价结果之后不能回填。

通用框架不选择标的、日期、交易时段或豁免组，不导入研究策略。回调仅选择容量假设；实际价格、可成交数量、费用和账务仍由引擎处理。
